# River Cannons - public playable

This is the self-contained, styled Version B playable prepared for browser sharing. The index.html bytes are unchanged from the current supplied build. The game includes its textures, meshes and audio. The submission history, AI conversation and development files are not part of this deployment package.

## Render static-site settings

- Repository branch: main
- Service type: Static Site
- Build command: echo ready
- Publish directory: .

The game is already built and needs no dependency installation on Render. Deploy the repository and use the resulting onrender.com address. Open that public address in a desktop or mobile browser. A public repository makes the HTML and its embedded game assets downloadable by anyone.
